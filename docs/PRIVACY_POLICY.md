# NoDupDownload Privacy Policy

Effective date: 2026-04-06

NoDupDownload("the extension") is a Chrome extension that helps prevent accidental duplicate downloads.

## Korean (한국어)

### 1. 수집 및 처리 정보

이 확장 프로그램은 중복 다운로드 감지를 위해 아래 정보를 브라우저 내에서 처리합니다.

- 다운로드 파일명
- 다운로드 URL(호스트 및 경로)
- 다운로드 상태(진행/완료/중단)
- 다운로드 시각(시작/완료 시각)
- 다운로드 관련 탭 ID

### 2. 사용 목적

처리된 정보는 아래 목적에만 사용됩니다.

- 중복 다운로드 가능성 판단
- 사용자 확인 UI(계속/취소) 표시
- 이전 다운로드 일자 안내

### 3. 외부 전송 및 제3자 제공

이 확장 프로그램은 사용자 데이터를 외부 서버로 전송하지 않습니다.
사용자 데이터를 제3자에게 판매하거나 공유하지 않습니다.

### 4. 저장 및 보관

- 중복 판정을 위한 통계는 확장 프로그램 메모리에서 일시적으로 처리됩니다.
- 다운로드 원본 이력은 Chrome 브라우저의 기본 다운로드 기록을 참조합니다.
- 별도의 원격 DB 또는 외부 저장소를 사용하지 않습니다.

### 5. 원격 코드

이 확장 프로그램은 원격 호스팅된 실행 코드를 로드하거나 실행하지 않습니다.

### 6. 아동 및 민감정보

이 확장 프로그램은 아동 대상 서비스가 아니며, 민감정보를 수집하도록 설계되지 않았습니다.

### 7. 정책 변경

정책이 변경되면 본 문서의 시행일(Effective date)을 업데이트합니다.

## English

### 1. Data Processed

The extension processes the following data in-browser for duplicate detection:

- Download filename
- Download URL (host and path)
- Download state (in progress / complete / interrupted)
- Download timestamps (start/end time)
- Related tab ID

### 2. Purpose of Processing

The processed data is used only to:

- Detect likely duplicate downloads
- Show user decision UI (Continue/Cancel)
- Display previous download date

### 3. Data Transfer and Sharing

The extension does not send user data to external servers.
The extension does not sell or share user data with third parties.

### 4. Storage and Retention

- Duplicate-detection stats are handled temporarily in extension memory.
- Source history is read from Chrome's built-in download history.
- No remote database or external storage is used.

### 5. Remote Code

The extension does not load or execute remotely hosted executable code.

### 6. Children and Sensitive Data

The extension is not designed for children and is not intended to collect sensitive personal data.

### 7. Policy Changes

If this policy changes, the effective date in this document will be updated.
